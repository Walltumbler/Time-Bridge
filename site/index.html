BROWSER CONNECTION

Add the extension

The extension connects a page to Desktop when the browser blocks direct local access. Open the extension on that page before connecting. Only pages you approve can manage their own alarms.

Chrome

Add to Chrome

The store listing is not published yet. For this development build, use the steps below.

Development installation
  1. Download the Chrome extension ZIP and extract it.
  2. Open chrome://extensions.
  3. Enable Developer mode → Load unpacked → choose the extracted folder containing manifest.json.
  4. Return to this page, open Timebridge from the extensions menu, and choose Connect this site.

Firefox

Add to Firefox

The signed add-on is not published yet. Temporary installation is available for testing.

Development installation
  1. Download the Firefox extension ZIP and extract it.
  2. Open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and select the extracted manifest.json.
  4. Return here and connect using the toolbar extension. Repeat installation after restarting Firefox.
FOR DEVELOPERS

A few lines. A real desktop alarm.

Use the JavaScript/TypeScript SDK in a website, a Node application on the same computer, or the local JSON API from another language.

Read the integration guide →

import { createTimebridge } from '@timebridge/sdk';

const clock = createTimebridge({ appName: 'My app' });
await clock.requestPermission();
await clock.createCountdown({
  durationSeconds: 10,
  icon: mySmallPngDataUrl, // optional
});
Need a hand?
  • Desktop not found: open Timebridge. If direct access is blocked, load the extension, open its toolbar button on this page, then choose “Browser extension only” above.
  • Browser asks for local-network access: this page needs to reach Timebridge on your own computer. You can allow it or use the extension instead.
  • Browser helper unavailable: install the desktop app and open it once. Check Desktop Settings for a helper error. Restart the browser after installation.
  • No sound: check Desktop Settings, choose your alarm output, and enable the optional volume override.
  • Permission revoked: reconnect and approve the site again. Revocation does not delete existing timers.
